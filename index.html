Exploring Exoplanets with Artificial Intelligence Using NASA Kepler Space Telescope Data

Three classifiers — Random Forest, XGBoost and a PyTorch 1D convolutional network — trained on an identical 36-feature set from NASA's cumulative Kepler Object of Interest table (N = 9,564), with every vetting-derived column removed, to classify each signal as CONFIRMED, CANDIDATE or FALSE POSITIVE and to separate label leakage from label-set choice.

⚙️ Trained & Evaluated Model Architectures

Random Forest

Baseline

100 trees under a fixed seed, drawing a random subset of features at each split and aggregating the votes — the conventional baseline for tabular problems of this size.

  • Missing values filled with the column median
  • SMOTE inside the training partition only
  • All six vetting-derived columns removed
  • Macro F1 .75 · AUC .961 (CONFIRMED vs rest)
Test accuracy (no vetting) 79%

XGBoost

Gradient Boosting

Builds trees in sequence, each fitting the residuals of its predecessors. The configuration was fixed in advance and not tuned: multi:softprob, learning rate .08, max depth 6, 250 estimators.

  • Highest AUC for CONFIRMED: .966
  • Macro F1 .76 · five-fold CV .739 (SD = .012)
  • Re-run on 3 feature sets × 2 label sets
  • Recall: CANDIDATE .55 · CONFIRMED .85 · FP .88
Test accuracy (no vetting) 79%

PyTorch 1D-CNN

Deep Learning

Two convolutional blocks — Conv1d(1→16) and Conv1d(16→32) — with batch normalisation, ReLU and max pooling, then a 64-unit dense layer. Convolution runs along the 36-feature vector: a comparison under a fixed representation, not convolution over light curves.

  • Adam, learning rate .0005, batch 64, 25 epochs
  • Dropout .3 · gradient-norm clipping at 1.0
  • CANDIDATE recall .62 exceeds its precision .50
  • Four points below XGBoost (McNemar p < .001)
Test accuracy (no vetting) 75%

3. Confusion Matrix — XGBoost (n = 1,913)

XGBoost classified 1,517 of 1,913 test KOIs correctly (accuracy .79) and made 396 errors. Recall: CANDIDATE .55, CONFIRMED .85, FALSE POSITIVE .88 (Table 4).

🔬 From the paper: almost everything goes wrong on CANDIDATE — of 449 instances the model kept 245, promoted 67 and demoted 137. CANDIDATE marks a signal whose vetting has not finished, so the label does not behave as a physical category, and some of the 67 promotions may anticipate confirmations rather than errors.

🔬 Scientific Deep Dive: Label Leakage vs. Label-Set Choice

🚨 1. Why Published Accuracies Disagree — Label Leakage

Published accuracies on the KOI catalogue range from below .80 to above .98. Six columns of the cumulative KOI table encode the outcome of NASA's automated vetting (the Robovetter) rather than a property of the object. The target, koi_disposition, is produced by the same procedure, so a model given these columns predicts an outcome from its own antecedents — label leakage in its textbook form. The highest catalogue-based figure, 98% (Sturrock et al.), was a two-class result (CONFIRMED vs FALSE POSITIVE, CANDIDATE held out) with the four flags still in the feature set.

🚩 koi_fpflag_ss

🚩 koi_fpflag_ec

🚩 koi_score

🚩 koi_pdisposition
Pipeline disposition (the vetting verdict)

✅ 2. One Design, Two Factors

With all six vetting-derived columns withheld and all three labels kept, random forest and XGBoost reach .79 and the 1D-CNN .75: roughly four fifths of KOI dispositions are recoverable from astrophysical and stellar parameters alone. The XGBoost configuration was then re-estimated across three feature sets and two label sets on the same split, seed and hyperparameters (table below):

  • Restoring the four flags raises three-class accuracy from .793 to .907; restricting the same 36 features to CONFIRMED vs FALSE POSITIVE raises it to .939.
  • The cell matching the design of Sturrock et al. (four flags, two labels) reaches .994 — above the 98% that study reported, so the published figure is reproducible and its distance from .79 is a matter of design alone.
  • Averaged over both orders, 11.7 of the 20.1 accuracy points belong to the label set and 8.5 to the four flags: the label set is the larger term.
  • koi_score and koi_pdisposition add only .018 (three-class) and .003 (binary) once the flags are present.

Accuracy on the KOI catalogue is therefore not interpretable unless both the feature set and the label set are disclosed.

📌 3. What the Results Do Not Support

  • Host-star split: 23.9% of records share a host star with another record. A split grouped by Kepler Input Catalog ID gives accuracy .779 and macro F1 .748 (against .793 and .758) — real leakage, but worth only about 1.4 points.
  • Measurement uncertainties: dropping every uncertainty column (leaving 16 features) lowers accuracy from .793 to .764 and macro F1 from .758 to .733 — a residual channel worth about three points.
  • Cross-validation: in the five-fold check (macro F1 .739, SD = .012), feature scaling was estimated across the complete dataset and no resampling was applied inside the folds.
  • Interpretability: SHAP was applied during development, but the multi-class output was handled incorrectly and the figures proved unusable; a corrected per-class analysis is the natural next step.
  • Representation: the 1D-CNN operated on a tabular vector rather than on photometry, so the comparison with light-curve architectures remains indirect.
  • Snapshot: a single catalogue snapshot was used; repeating the analysis on a later release would separate genuine misclassification from anticipation of reclassification.
